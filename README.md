# batchy

Batchy — это рабочий инструмент для технолога-косметолога-любителя. 
Приложение помогает хранить ингредиенты, рецептуры, историю замесов и закупки в одном месте, вместо того чтобы разносить данные по таблицам, заметкам и отдельным файлам.
